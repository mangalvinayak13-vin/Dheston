# Figures

Every figure is a 300 dpi PNG and a PDF with the same stem, 16:9-friendly, on an opaque light panel so it reads on dark and light slide backgrounds. This file is written by `dh2/report_figures.py` (the registry `REGISTRY`), so it cannot drift from the files. Figures marked *new* are drawn by `dh2/report_figures.py` from the result files named in the last column and from `results/metrics.json`; figures marked *copy* are the work packages' own figures, copied and also written as PDF (the raster at 300 dpi).
