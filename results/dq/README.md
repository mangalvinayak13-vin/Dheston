# Data-quality report (NIFTY 50 index options, NSE end-of-day files)

Generated by `python3 -m dh2.dq` from the raw files in `data/nse_index/` (2,470 daily files, 2016-10-03 to 2026-10-06).
Nothing here is typed by hand: every number comes from the script's run. The filters are the ones in `dh2/data.py`, applied by
re-running that module's own functions and constants (`MIN_DAYS` = 3, `MIN_PRICE` = Rs 1,
`MAX_LOG_MONEYNESS` = 0.22, `PARITY_STRIKES` = 6) with a counter after each step.

## Check against the surfaces every finished run used

The replicated funnel reproduces the cached surfaces (`data/cache/surfaces.pkl`) exactly: 2470 cached surfaces checked
(quote count, expiry count, rate, forwards and expiry times), **0 mismatches**; the funnel finds
2470 usable days against 2470 cached surfaces; days that are usable in the replication
but absent from the cache: 0.

## Headline (all years)

- 2,470 daily files; **2,470 days (100.0%) give a usable surface**.
- 5,254,005 NIFTY option rows in the files -> 1,517,128 traded (volume > 0, 28.9%) -> **736,313 final quotes**
  (14.0% of all NIFTY option rows, 48.5% of the traded ones).
- A usable day has 298 quotes on average (median 311) in 6.9 expiries (2 to 11).
- Shortest expiry on usable days: <= 7 days on 1,266 days, 8-14 days on 831, 15-30 days on 323, more than 30 days on 50
  (median 7 days).

## Things to know

- The stored files contain index options only (NIFTY and, from 2024, BANKNIFTY), so "option rows" does not include stock options.
  Only NIFTY is used.
- NSE's closing price (`ClsPric`) is reported even for strikes that did not trade that day, so the volume > 0 step removes a large share
  of the file; those prices are stale settlement-style values, not trades.
- The out-of-the-money split uses each expiry's parity forward, so it comes after the expiry tests; the brief's list order differs from the
  code order only in presentation.
- No-arbitrage violations are measured separately (`dh2/noarb.py`, `noarb_by_year.csv`, `noarb_sensitivity.csv`); the dataset is not filtered for them
  (DECISIONS.md, decision 4).
