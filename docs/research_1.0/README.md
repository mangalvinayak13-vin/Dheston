# What the 1.0 research project contains, in plain English

Two reports on the original research repository (`double-heston-inverse-calibration`, the project 2.0 was forked from). Written by reading
the repository's code and result files; every function description comes from its docstring or first lines, and "not read" is stated
where it was not. Six headline numbers in the Viraj report were re-checked against the cited result files (all matched).

- `viraj_choudhary_work.md`: the pricing engine, the parameter-recovery studies, the neural networks, the sealed test protocols.
- `dhruva_ambhaikar_work.md`: the PINN experiments (versions 1 to 6), the real-market tests and the fine-tuned calibrator.

Neither project's code is used by DH2.0; they are the "before" that 2.0 is compared against (`COMPARISON_1.0_vs_2.0.md`).
